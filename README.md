# Анализ зарплат

# Анализ влияния характеристик сотрудников на уровень заработной платы

## 📌 Описание проекта

Итоговая работа по программе «Аналитик данных» (Финансовый университет при Правительстве РФ).

**Цель:** проанализировать, как на уровень заработной платы влияют:
- Уровень образования
- Стаж работы
- Возраст
- Пол

**Задача машинного обучения:** предсказание уровня заработной платы по полу, должности и уровню образования.

Проект выполнен в **Google Colab**.

> ⚠️ **Примечание по запуску:** Блокнот написан для Google Colab. В коде используется путь к датасету `/content/Salary_Data.csv`. При запуске в другом окружении путь нужно скорректировать на `data/raw/Salary_Data.csv`.

## 📊 Описание датасета

Файл `Salary_Data.csv` содержит информацию о зарплатах сотрудников.

| Колонка | Описание | Тип |
|---------|----------|-----|
| Age | Возраст сотрудника | float64 |
| Gender | Пол | object |
| Education Level | Уровень образования | object |
| Job Title | Должность | object |
| Years of Experience | Стаж работы (лет) | float64 |
| Salary | Зарплата | float64 |

**Размер:** 6 704 строки × 6 колонок.

**Пропуски в данных:** от 2 до 5 значений в каждой колонке.

**Дубликаты:** 4 912 строк (~73%). Было принято решение не удалять их, а добавить колонку `EmployeeID` с уникальным номером, так как совпадения обусловлены тенденцией (ровесники, одинаковый стаж), а не дублированием одного человека.

## 🔍 Этапы работы

### 1. ETL и EDA

- Очистка данных от пропусков (заполнение модой и средним по группам).
- Удаление строк с полными пропусками.
- Добавление колонки `EmployeeID`.
- Стандартизация категориальных значений.
- Исправление аномалий (зарплаты ниже 10 000 — опечатки, умножены на 100).

### 2. Визуализация и корреляционный анализ

- Распределение по полу: Male — 55%, Female — 45%, Other — 0.2%.
- Box Plot по возрасту, стажу и зарплате.
- Зависимость зарплаты от уровня образования.
- Зависимость зарплаты от опыта работы.
- Зависимость зарплаты от возраста.
- Гендерный разрыв в зарплатах.

### 3. Статистический анализ гендерного разрыва

- Средняя зарплата мужчин: **121 378.21**
- Средняя зарплата женщин: **108 008.66**
- Разница: **13 369.55** (11.0%)
- T-тест Стьюдента: p-value = 0.0000 — разрыв **статистически значим**.

### 4. Множественная регрессия

| Фактор | Влияние на зарплату |
|--------|---------------------|
| Каждый уровень образования | +6 217 |
| Каждый год стажа | +8 792 |
| Каждый год возраста | −2 112 |
| Мужчины (vs женщины) | +7 374 |
| **R²** | **0.680** |

**Вывод:** опыт — главный фактор, он ценится больше образования. Возраст имеет отрицательный эффект. Гендерный разрыв подтверждён.

### 5. Машинное обучение

**Задача:** предсказание зарплаты по полу, должности и уровню образования.

**Протестировано 8 моделей:**

| Модель | R² | RMSE | MAE |
|--------|-----|------|-----|
| **Random Forest** | **0.9722** | **8 705** | **3 380** |
| XGBoost | 0.9683 | 9 274 | 5 573 |
| Decision Tree | 0.9659 | 9 617 | 3 278 |
| Gradient Boosting | 0.9122 | 15 434 | 11 331 |
| Linear Regression | 0.6784 | 29 531 | 23 283 |
| Lasso Regression | 0.6784 | 29 531 | 23 283 |
| Ridge Regression | 0.6784 | 29 532 | 23 286 |
| SVR | 0.0147 | 51 694 | 44 810 |

**Лучшая модель — Random Forest:**
- R² = 0.9722 (объясняет 97% вариации зарплат)
- RMSE = 8 705
- MAE = 3 380
- Минимальное переобучение (разница train/test = 0.02)

### 6. Важность признаков (Random Forest)

| Категория | Важность |
|-----------|----------|
| Возраст и опыт | **79.8%** |
| Должность | 17.4% |
| Образование | 2.2% |
| Пол | 0.7% |

**Главный фактор — опыт работы.** Образование и пол имеют минимальное влияние.

### 7. Практические выводы

1. **Для HR-отдела:** фокус на удержании опытных сотрудников.
2. **Для сотрудников:** карьерный рост и опыт важнее дополнительного образования.
3. **Для работодателя:** опыт кандидата — лучший прогноз будущей зарплаты.
4. **Гендерный разрыв:** подтверждён статистически (11%), особенно на должности Product Manager (−35.9% в пользу женщин).
